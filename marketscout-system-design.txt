============================================================
1. Tổng quan hệ thống
============================================================
MarketScout là SaaS giúp SME Việt Nam xác minh đối tác thương mại quốc tế và tìm kiếm đối tác mới qua chat tự nhiên. User nhập yêu cầu → hệ thống thu thập dữ liệu từ nhiều nguồn → chấm điểm 8 tiêu chí → báo cáo 0–100 + đề xuất giao dịch an toàn.

1.1 Luồng tổng thể
------------------

  Bước | Hành động                                                | Tier            | Quota
  -----+----------------------------------------------------------+-----------------+---------
  1    | Chat Box: nhập yêu cầu tự nhiên (tìm đối tác / xác minh) | Tier 0 — Chat   | Miễn phí
  2    | Manager Agent tìm kiếm → trả danh sách công ty           | Tier 1 — Search | Miễn phí
  3    | Quick Scan P1 + P6, ~30 giây                             | Tier 2 — Quick  | Miễn phí
  4    | Deep Verify 8 pillars, 5–8 phút                          | Tier 3 — Deep   | -1 quota
  5    | Report: score 0–100 + 8 pillar details + Deal Safety     | Output          | —


1.2 Các thành phần backend
--------------------------

  Thành phần         | Vai trò                                         | File chính
  -------------------+-------------------------------------------------+--------------------------------
  Chat Service       | Chat box, conversation history, intent routing  | ChatService, ChatController
  Manager Agent      | Gemini: detect intent, tìm đối tác, orchestrate | ManagerAgent
  Auth Service       | Đăng ký, đăng nhập, JWT, email verify           | UserService, AuthController
  Quota Service      | Kiểm tra và trừ quota trước Deep Verify         | QuotaService
  Crawler Service    | Thu thập data: MST, GLEIF, VCCI, Tavily...      | CrawlerService, *Crawler.java
  Scoring Engine     | Chạy 8 pillar, tính điểm, Hard Stop             | ScoringEngineService
  Report Service     | Tạo report, quản lý job pipeline                | ReportService, ReportController
  Deal Safety Engine | Đề xuất Incoterm, payment method                | DealSafetyService
  Email Service      | Gửi email verify, reset pass — Mailtrap         | EmailVerificationService
  Redis              | Refresh token, verify token, blacklist          | RefreshTokenService

3. Chat Box & Find Partners
============================================================
Chat Box là entry point của toàn bộ app. User không dùng form — họ chat tự nhiên. Manager Agent (Gemini) detect intent và route đến đúng service.

3.1 Intent routing
------------------

  Intent         | Action         | Ví dụ input
  ---------------+----------------+-----------------------------------------
  find_partner   | FIND_PARTNERS  | "tìm nhà cung cấp vải cotton Trung Quốc"
  verify_company | TRIGGER_VERIFY | "xác minh công ty Alibaba Group"
  ask_report     | GET_REPORT     | "kết quả verify lúc nãy thế nào"
  general        | CHAT_RESPONSE  | "Incoterm FOB là gì?"


3.2 Nguồn dữ liệu Find Partners
-------------------------------

  Nguồn             | Data gì                  | Free tier      | Ghi chú
  ------------------+--------------------------+----------------+--------------------------------
  Tavily Search API | Web search có cấu trúc   | 1,000/tháng    | Find Partners flow
  GLEIF API         | Legal Entity Identifier  | Không giới hạn | ISO 17442 — thay OpenCorporates
  api.tracuunnt.com | MST công ty VN           | Không giới hạn | Tổng cục Thuế, P1 source
  Google Places API | Địa chỉ, phone, rating   | $200 credit/T  | Verify physical existence
  OpenSanctions     | OFAC/EU/UN sanctions     | Self-host free | Docker, P6 bắt buộc
  VCCI eCoSys       | Certificate of Origin VN | Không giới hạn | Scrape, P3 source

OpenCorporates đã bị loại: gói rẻ nhất £2,250/năm, không có free tier cho commercial use. Thay bằng GLEIF — miễn phí, uy tín hơn, ISO standard.

4. Quota Logic
============================================================
Quota là số lần Deep Verify user được phép trong chu kỳ billing. Chat và Quick Scan không tốn quota.

4.1 Business rules
------------------

  Rule              | Chi tiết
  ------------------+-------------------------------------------------------------------------
  Free plan         | 2 verify LIFETIME — không reset (cycle_reset_at = NULL)
  Paid plans        | Reset theo ngày anniversary, không phải ngày 1 mỗi tháng
  Chat + Quick Scan | Không trừ quota — miễn phí vĩnh viễn
  Deep Verify       | Trừ 1 quota NGAY KHI BẮT ĐẦU, không phải khi xong
  Lý do trừ trước   | Tránh user refresh liên tục → gọi API nhiều lần miễn phí
  Quota = 0         | Block Deep Verify, hiện upsell modal. Vẫn cho Chat + Search + Quick Scan
  Report fail       | Admin hoàn quota thủ công qua PATCH /admin/users/{id}/quota


4.2 Atomic deduct query
-----------------------
@Modifying
@Query("UPDATE Users u SET u.quotaRemaining = u.quotaRemaining - 1,"
+ "u.quotaUsedThisCycle = u.quotaUsedThisCycle + 1 "
+ "WHERE u.id = :userId AND u.quotaRemaining > 0")
int deductOneQuota(@Param("userId") UUID userId);
// 1 = OK  |  0 = hết quota  |  race condition safe

5. 8-Pillar Scoring Pipeline
============================================================
Deep Verify chạy 8 pillar theo thứ tự. P6 (Sanctions) có Hard Stop — phát hiện cấm vận → dừng toàn bộ pipeline ngay.

5.1 8 Pillars
-------------

  #  | Pillar    | Check gì                                   | Weight | Hard Stop | Nguồn data
  ---+-----------+--------------------------------------------+--------+-----------+---------------------------
  P1 | Pháp lý   | Tax code, đăng ký, trạng thái active       | 18%    | Không     | MST (VN), GLEIF (quốc tế)
  P2 | Digital   | Domain age, website, LinkedIn presence     | 10%    | Không     | WHOIS
  P3 | Trade     | Xuất nhập khẩu thực tế, số năm hoạt động   | 18%    | Không     | VCCI eCoSys, ITC Trade Map
  P4 | Identity  | Tên/địa chỉ khớp giữa các nguồn            | 12%    | Không     | Cross-check
  P5 | Tài chính | Thuế, nợ thuế, báo cáo tài chính           | 14%    | Không     | Tổng cục Thuế VN
  P6 | Sanctions | OFAC, EU, UN cấm vận. SWIFT/BIC validation | 12%    | CÓ ⚠      | OpenSanctions, SWIFT
  P7 | Deal      | Incoterm thường dùng, payment history      | 8%     | Không     | Trade history
  P8 | Physical  | Ảnh nhà xưởng — TinEye + Gemini vision     | 8%     | Không     | TinEye, user upload


5.2 Cache TTL
-------------

  Pillar       | TTL     | Lý do
  -------------+---------+----------------------------------------
  P1 Pháp lý   | 7 ngày  | Đăng ký thay đổi chậm
  P2 Digital   | 3 ngày  | Domain, website thay đổi vừa phải
  P3 Trade     | 7 ngày  | Lịch sử thương mại ổn định
  P6 Sanctions | 24 giờ  | Danh sách cấm vận cập nhật thường xuyên
  P8 Images    | 30 ngày | Ảnh nhà xưởng hiếm khi thay đổi


5.3 Tính overall score
----------------------
Weighted average của các pillar CÓ score — pillar null bị bỏ qua, weight được renormalize. Không phạt user vì thiếu data.
// P8 null → tổng weight 7 pillar còn lại = 92%
overallScore = sum(score[i] * weight[i]) / 92

5.4 Pipeline flow
-----------------
POST /api/v1/reports/deep-verify { entityName, countryIso2 }
→ 1. quotaService.deductQuota(userId)   ← ATOMIC
→ 2. Tạo Report (score = null) + ReportJob (status = queued)
→ 3. Return 202 Accepted { reportId }
→ [ASYNC] ScoringEngineService.runDeepVerify(reportId)
Loop i = 1→8: crawl → score → save pillar
if (i==6 && score==0) → HARD STOP
calculateOverallScore() → save
→ [Frontend] GET /reports/{id}/status  mỗi 3s

6. Crawler & Data Sources
============================================================
Crawler thu thập dữ liệu trước khi Scoring Engine chấm điểm. Kết quả cache theo entity + pillar để tránh gọi lặp.

6.1 Nguồn dữ liệu theo pillar
-----------------------------

  Pillar     | Nguồn                             | Loại        | Free tier
  -----------+-----------------------------------+-------------+------------------
  P1 VN      | api.tracuunnt.com (Tổng cục Thuế) | HTTP REST   | Không giới hạn
  P1 quốc tế | GLEIF API (gleif.org)             | REST API    | Không giới hạn
  P2         | WHOIS (domaintools.com)           | HTTP scrape | Không giới hạn
  P3         | VCCI eCoSys, ITC Trade Map        | HTTP scrape | Giới hạn (ITC)
  P4         | Google Places API                 | REST API    | $200 credit/tháng
  P5         | Tổng cục Thuế VN                  | HTTP scrape | Không giới hạn
  P6         | OpenSanctions (self-hosted)       | Local DB    | Miễn phí tự host
  P6 Bank    | SWIFT Directory                   | HTTP scrape | Không giới hạn
  P8         | TinEye API                        | REST API    | 150 lookups/tháng
  Search     | Tavily Search API                 | REST API    | 1,000 calls/tháng


6.2 Entity Cache
----------------
Cache key format: {pillar_no}:{entity_name_lowercase}:{country_iso2}
// Ví dụ: "1:acme gmbh:de"
cache = entityCacheRepo.findById(cacheKey)
if (cache != null && cache.expiresAt > now) return cache.data
// Sau khi gọi API thành công → save cache

6.3 GLEIF API
-------------
Thay thế OpenCorporates. Chuẩn ISO 17442, IMF/BIS/FSB bảo trợ. Miễn phí, không cần API key.
GET https://api.gleif.org/api/v1/fuzzycompletions?field=fulltext&q=Deutsche+Bank
GET https://api.gleif.org/api/v1/lei-records?filter[entity.legalName]=Alibaba

6.4 SWIFT/BIC flow (P6)
-----------------------

  Bước | Hành động                                        | Source
  -----+--------------------------------------------------+--------------------------
  1    | User cung cấp SWIFT code của ngân hàng đối tác   | Input từ form verify
  2    | Validate format: 8 hoặc 11 ký tự AAAA-BB-CC-XXX  | Regex validation
  3    | Lookup → tìm tên ngân hàng, quốc gia             | SWIFT Directory scrape
  4    | Kiểm tra ngân hàng có trong sanctions list không | OpenSanctions cross-check
  5    | Trả kết quả: valid/invalid + tên ngân hàng thật  | Score P6
